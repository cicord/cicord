```text
git push ──▶ cicord serve ──▶ Discord
             ├─ reconciles servers (roles, categories, channels, permissions…)
             ├─ runs N bots × M servers with TypeScript plugins
             ├─ admin console (every change is a git commit or a pull request)
             └─ API for your community portal (React SDK)
```

## What you get

<CardGrid>
  <Card title="Servers as code" icon="document">
    Roles, categories, channels, permissions, Community settings, AutoMod, onboarding, emojis and
    more, declared in YAML. `cicord plan` shows the diff, the runtime applies it.
  </Card>
  <Card title="One runtime, many bots" icon="server">
    A single `cicord` binary hosts every bot of your community, with hot reload of new revisions and
    no gateway reconnect.
  </Card>
  <Card title="Sandboxed plugins" icon="puzzle">
    Plugins are TypeScript modules with explicit capabilities. Nine official plugins ship in the
    binary: welcome, onboarding, tickets, polls, levels, moderation and more.
  </Card>
  <Card title="Git stays the source of truth" icon="code-branch">
    Edits made in the admin console come back to the repository as commits or pull requests, with
    comments and formatting kept.
  </Card>
</CardGrid>
