# Contributing to Cicord

Thanks for your interest in Cicord! Bug reports, ideas, documentation fixes, plugins and code
are all welcome.

The contributor guide is in the documentation:
**[cicord.dev/docs/project/contributing](https://cicord.dev/docs/project/contributing/)**
(how to report a bug or propose a change, building and testing, the checks CI runs, pull
request conventions).

- Questions and ideas: the [community Discord](https://discord.gg/qTt5S2Fe4m) or
  [GitHub discussions](https://github.com/cicord/cicord/discussions).
- Security issues: never in a public issue, see [SECURITY.md](SECURITY.md).

By contributing, you agree that your contributions are licensed under the
[Apache License 2.0](LICENSE) (section 5). Everyone taking part follows the
[Code of Conduct](CODE_OF_CONDUCT.md).
